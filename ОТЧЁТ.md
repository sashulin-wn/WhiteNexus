# v2rayNG — UI-форк по вашим критериям

Собранный APK, исходники и скриншоты реального интерфейса. Ядро (Xray/libv2ray, VPN-сервис,
маршрутизация, конфиги) **не менялось** — только слой интерфейса и его состояние.

Готовые файлы: папка `build-out/`
* `v2rayNG_2.4.0-fdroid_arm64-v8a.apk` — для современных телефонов (рекомендуется)
* `v2rayNG_2.4.0-fdroid_universal.apk` — универсальный
* `screen-home-dark.png`, `screen-home-light.png` — скриншоты реального экрана

## Что сделано

### 1. Главный экран: карточка быстрого подключения

* **«Подключить» / «Автоподключение»** — пара кнопок над карточкой.
* **Большая карточка**: флаг, страна/город, IP-адрес и порт, статус соединения.
* **Автоматический выбор** — выбирает лучший вариант **внутри активной IP-группы** по ping.
* **Варианты** — чипы с протоколом, портом и своим ping; активный выделен зелёным.
* **Подключение именно выбранной конфигурации** — по GUID; запущенный сервис перезапускается с ней.

### 2. Группировка серверов по IP

* Одинаковый IP → одна карточка **внутри одной подписки**.
* Разные подписки **не объединяются**.
* Каждая конфигурация самостоятельна: свой GUID, порт, протокол, свои действия; внутри
  карточки — раскрывающийся список вариантов, каждый подключается отдельно.

### 3. Действия в карточке сервера

* **Поделиться / Редактировать / Удалить** — сохранены (меню «⋮»).
* **Избранное (★)** — при первом избранном **автоматически появляется группа «Избранное»**,
  исчезает при удалении последнего.
* **Закрепление (📌)** — закреплённые серверы поднимаются наверх подписки (видно на скриншоте:
  USA, New York стоит выше остальных).
* Списки избранного и закреплений чистятся при удалении сервера.

### 4. Нижняя навигация

Пять разделов: **Группы · Маршрутизация · Главная · Приложения · Настройки**, активный — зелёный.
Иконки нарисованы векторно по вашему референсу (слои, маршрут с точками, дом, 4 квадрата, шестерёнка).

### 5. Проксируемые приложения

Иконки выбранных приложений и переход в экран выбора приложений.
